# musti.exe

akaMusti'nin kisisel sitesi — 2000'ler (Neocities) estetiginde, yesil/siyah retro tema.

- `index.html` — tek sayfa: navigasyon, hakkımda, sosyal medya, projeler ve güncellemeler
- `style.css` — sabit 900px, üç sütunlu retro düzen
- `assets/images/` — damga, buton, ayırıcı ve header görselleri
- `assets/vendor/` — Kenney Pixel UI Pack (CC0), header görselinin kaynagı

Görseller Kenney (CC0), goooby ve milo-html kaynaklarından alınmıstır; haber vermeksizin hotlink yapılmamıstır.
